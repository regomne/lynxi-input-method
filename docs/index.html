iPHONE · iPAD · RIME

双拼如意，
词随心动。

灵犀输入法是一款专注双拼体验的中文键盘。候选生成、智能纠错与词频学习均在设备本地完成。

查看启用步骤 GitHub

简洁，但不简单

围绕中文双拼输入打磨，不添加广告、跟踪或无关功能。

多种双拼方案

支持自然码、小鹤、微软、搜狗、智能 ABC、拼音加加和国标等常用方案。

本地智能输入

基于 Rime 在设备上生成候选，支持智能纠错和本地词频学习。

可管理的词库

支持自定义词库与 Rime 配置，保留输入方式的自主权。

自主同步

可通过自己的 WebDAV 服务或系统“文件”管理词库数据。

开始使用

安装并打开灵犀输入法后，按以下步骤添加键盘。

  1. 打开 iOS“设置”。
  2. 进入“通用” → “键盘” → “键盘”。
  3. 点击“添加新键盘”。
  4. 在第三方键盘中选择“灵犀输入法”。
  5. 添加后再次点击“灵犀输入法”。
  6. 如需自定义词库或词库网络同步，可开启“允许完全访问”。
  7. 在任意输入框长按或点击地球键，切换到“灵犀输入法”。

隐私是默认设置

基础中文输入、智能纠错、词频学习等主要功能无需完全访问。

灵犀输入法不会将您的键入内容发送给开发者或任意第三方，不包含广告、用户跟踪或第三方分析服务。
