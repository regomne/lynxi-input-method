# 灵犀输入法

一款专注于双拼输入体验的 iPhone 与 iPad 中文输入法，基于 Rime 输入引擎，支持多种常用双拼方案、本地词频学习和自定义词库。

## 主要功能

- 支持自然码、小鹤、微软、搜狗、智能 ABC、拼音加加、国标等双拼方案
- 基于 Rime 的本地中文候选生成
- 支持用户词频学习和自定义词库
- 支持中英文、数字和常用符号输入
- 支持触摸纠偏、空格滑动光标等输入辅助功能
- 支持通过 WebDAV 或系统“文件”进行词库同步
- 支持导入和管理 Rime 配置

## 隐私与完全访问

基础中文输入无需开启“完全访问”。不开启完全访问时，灵犀输入法会使用键盘扩展内置的基础词库，键入内容不会发送给开发者。

开启完全访问后，可以使用主 App 与键盘之间的共享设置、用户词典、词频学习及同步数据。WebDAV 只会连接您自行配置的服务器。

完整说明请阅读[灵犀输入法隐私政策](https://regomne.github.io/lynxi-input-method/)。

## 开始使用

安装并打开灵犀输入法后：

1. 前往 iOS“设置” → “通用” → “键盘” → “键盘”。
2. 点击“添加新键盘”，选择“灵犀输入法”。
3. 在任意输入框中通过地球键切换到灵犀输入法。
4. 如需共享词库、词频学习或同步功能，可在键盘设置中选择开启“完全访问”。

## 系统要求

- iOS 18.0 或更高版本
- 支持 iPhone 与 iPad
