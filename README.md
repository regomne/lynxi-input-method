# 灵犀输入法

一款专注于双拼输入体验的 iPhone 与 iPad 中文输入法，基于 Rime 输入引擎，支持多种常用双拼方案、本地词频学习和自定义词库。

## 主要功能

- 支持自然码、小鹤、微软、搜狗、智能 ABC、拼音加加、国标等双拼方案
- 基于 Rime 的本地中文候选生成
- 支持用户词频学习和自定义词库
- 支持中英文、数字和常用符号输入
- 支持触摸纠偏、空格滑动光标等输入辅助功能
- 支持通过 WebDAV 或系统“文件”进行词库同步
- 支持导入和管理 Rime 配置

## 隐私与完全访问

基础中文输入、智能纠错、词频学习等主要功能无需开启“完全访问”。不开启完全访问时，灵犀输入法会使用键盘扩展内置的基础词库和本地学习数据。

开启完全访问后，可以使用自定义词库和词库网络同步功能。WebDAV 只会连接您自行配置的服务器。灵犀输入法不会将您的键入内容发送给开发者或任意第三方。

完整说明请阅读[灵犀输入法隐私政策](https://regomne.github.io/lynxi-input-method/privacy/)。

## 开始使用

安装并打开灵犀输入法后：

1. 打开 iOS“设置”。
2. 进入“通用” → “键盘” → “键盘”。
3. 点击“添加新键盘”。
4. 在第三方键盘中选择“灵犀输入法”。
5. 添加后再次点击“灵犀输入法”。
6. 如需使用自定义词库或词库网络同步，可开启“允许完全访问”；基础中文输入、智能纠错和本地词频学习不需要此权限。
7. 在任意输入框中长按或点击地球键，切换到“灵犀输入法”即可开始使用。

## 系统要求

- iOS 15.0 或更高版本
- 支持 iPhone 与 iPad
